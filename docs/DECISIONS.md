# 产品决策与非目标

## 已锁定决策

- 产品是可复制的工作区内 Harness，不是全局 Agent 管理器。
- `Huajuan-Harness` 便携包的一级父目录就是工作区；不设计路径选择步骤，也不要求用户拆散隐藏文件。
- 核心用途合并了旧版“使用模式”和“最终目标”。
- 用户只输入称呼、工作区名称和最后备注。
- 主要 Agent 为 Claude Code、Codex、Cursor、Trae、WorkBuddy、通用 Agent。
- 保护路径多选的含义是默认只读；启动器与 Marker 无需用户选择，自动保护。
- 用户只决定是否开启自动进化，其他记忆和淘汰判断由固定工作流完成。
- 不要求用户解释顶层目录含义，也不要求用户理解空目录内部结构。
- 工作区级 Rule、Skill、Workflow、MCP、Memory 与 Proposal 全部进入 `.harness`。
- Dashboard 是离线生成快照，并提供安全的查看、筛选、复制与导出功能。
- Huajuan 只规定知识库主题、结构、分类、格式、引用和生命周期必须明确；具体规则必须由 Agent 根据现状提案并经用户确认。
- 六份知识契约与质量检查通过前保持 `BLOCKED`，不得执行正式入库；通过后才进入 `READY`。
- 正式内容兼容 Obsidian：Markdown 使用 Frontmatter / WikiLink，非 Markdown 使用 Sidecar，并维护必要索引。
- 对话与定时采集都执行沉淀判断；重复、冲突、过期和被替代内容进入复审或淘汰 Proposal，永不自动删除。
- 卸载只删除 `.harness`，并推荐先导出用户沉淀。

## 强制安全决策

- 普通工作任务不得修改启动器与 Marker；用户明确要求优化 Harness 时，治理提示词、Rules、Skills、Workflows、Agent 适配和模板可在确认范围、风险、验证与回滚后受控修改。
- 不修改 Agent 全局配置，不在工作区外安装 Skill / MCP。
- MCP 不保存秘密，不自动启用，不未经确认扩大权限或传输数据。
- 高风险文件操作必须先列出对象、影响、验证与回滚并得到确认。
- 语义相似不能成为正式知识关系。
- Proposal 永远不自动应用；资产永远不自动删除。

## 非目标

- 不提供云同步、账户、团队权限或远程数据库。
- 不成为 MCP Runtime，也不代替 Agent 的安全凭据系统。
- CLI 不替 Agent 进行语义分类或自行决定目录；Agent 只能依据已确认契约提出和实施整理方案。
- 不复制整个项目到知识区，不保存完整对话为记忆。
- 不提供独立文件权限系统；约束通过系统协议、保护路径和确认门禁实现。
- 不让 Dashboard 执行 Shell 或修改工作区。
- 不承诺对任意自然语言关系进行自动推断。
- 不把向量数据库、语义搜索或云服务设为第一版 READY 的硬依赖；Markdown 文件系统仍是唯一真实数据源。

## 可兼容但不出现在用户界面的能力

- `--workspace` 仅保留给自动化和旧调用兼容，不进入启动器、Dashboard 命令或用户流程。
- `--answers` 用于确定性测试和批量分发，仍由 `applyAnswers` 强制安全不变量。
- `uninstall --yes` 用于自动化验收，正常用户使用选项式确认。
