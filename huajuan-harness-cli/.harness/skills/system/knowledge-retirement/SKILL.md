# Knowledge Retirement

用于处理重复、冲突、过期、失效或已被替代的知识。

1. 查找来源、反向链接、历史版本和替代知识。
2. 选择 `merge`、`revise`、`review`、`deprecate` 或 `quarantine`，说明证据。
3. 涉及正式知识语义、分类变化或移动时生成 Proposal 并等待确认。
4. 批准后保留来源，写明原因、`superseded_by`、时间和验证结果。
5. 更新索引、WikiLink、Manifest 和质量报告。
6. 不自动删除知识或原始来源。
