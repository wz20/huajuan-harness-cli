# Workspace Safety：边界与高风险操作

- 只在 WORKSPACE 指定的真实工作区内操作，路径不得通过相对路径或符号链接越界。
- 用户选择的保护路径默认只读；不得创建、修改、移动、重命名、覆盖或删除。
- `.git`、凭据、环境变量文件和密钥材料按敏感路径处理，只读取任务必需的最少信息。
- 移动、重命名、覆盖、删除、批量改写、启用 MCP 和外部数据传输前，列出对象、影响、验证、回滚并请求确认。
- CLI 与 Marker 运行内核默认受保护。用户明确要求优化 Harness 时，可在给出范围、风险、验证和回滚并获得确认后修改治理层文件。
- Evolution Proposal 只能生成与展示，未经批准不得应用；`autoApply` 必须保持 `false`，删除永不自动执行。
- Harness 不修改操作系统文件权限，不上传工作区数据，不保存完整聊天，不泄露敏感信息。
