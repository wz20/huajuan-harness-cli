# Completion：完成检查

完成前逐项确认：

- 工作区是否 READY；若未 READY，是否只进行了允许的扫描、确认和契约维护；
- 新增内容是否符合 STRUCTURE、TAXONOMY、CONTENT_SCHEMA、REFERENCE_RULES 与 LIFECYCLE；
- 结果是否满足当前任务，文件位置是否明确；
- 临时文件是否清理，权限与受保护路径是否遵守；
- 来源、显式关系、失效链接和 Sidecar 是否完整；
- 是否应记录 Preference、Decision、Lesson 或 Bad Case；
- 是否需要 Proposal 或淘汰建议，且是否保持未自动应用、未自动删除；
- 新增 Rule、Skill、Workflow 或 MCP 是否位于正确的 `.harness` 用户目录且有真实证据；
- Doctor 是否通过或已列出问题；
- Dashboard 是否已重新生成。
- 本次对话是否已明确给出无需沉淀、新增、合并、更新、淘汰候选或 Harness 资产沉淀结论；
- knowledge scan / lint 是否已刷新，分类索引、WikiLink、Manifest 与 Sidecar 是否同步。
