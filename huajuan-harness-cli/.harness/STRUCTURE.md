这是当前工作区目录结构与文件归属的长期规范。它不是 CLI 根据文件名一次性猜出的结果，而是 Agent 只读观测后与用户多轮确认、最终沉淀的工作区事实。

## 维护流程

1. Agent 只读扫描实际目录、技术栈、入口文件、内容类型和已有规范。
2. 区分“可由证据确认的事实”与“需要用户决定的长期约定”。
3. 只向用户询问会影响目录职责、文件放置、命名、保护、归档或新增顶层目录的不确定项。
4. 用户确认后更新本文件；随后才允许按确认方案创建或调整结构。
5. 以后新增顶层目录、改变目录职责或迁移大量文件前，必须再次确认并同步本文件。
